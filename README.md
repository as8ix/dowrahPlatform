# لوحة تحكم الدورة القرآنية (Quran Course Dashboard) ✨🏆

لوحة تحكم احترافية وتفاعلية لمتابعة إنجازات الطلاب في الدورات القرآنية، مدمجة بملف إكسل لتحديث البيانات تلقائياً.

## المميزات (Features)
- 📊 **إحصائيات مباشرة**: متابعة الختمات، عدد الصفحات، ونسبة الإنجاز.
- 🎭 **كشف النتائج (Results Reveal)**: تأثيرات بصرية مشوقة (Skeletons, Blur, Confetti) للإعلان عن النتائج النهائية.
- 📑 **تكامل الإكسل**: قراءة البيانات مباشرة من ملف `quran_data.xlsx`.
- 📱 **تصميم عصري**: واجهة متجاوبة بالكامل بدعم للغة العربية.
- 🎬 **تأثيرات سينمائية**: تسلسل ظهور للبيانات يعطي طابعاً احتفالياً.

## كيفية الاستخدام (Usage)
1. قم بتحديث البيانات في ملف `data/quran_data.xlsx`.
2. احفظ الملف، وستقوم لوحة التحكم بالتحديث تلقائياً (عند تشغيلها محلياً أو بعد الدفع لـ GitHub).

## التشغيل المحلي (Local Development)
```bash
npm install
npm run dev
```
